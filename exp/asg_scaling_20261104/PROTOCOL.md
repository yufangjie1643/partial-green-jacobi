# 扩规模实验协议

在本轮正式计时前确定以下实验范围。原完成目录及其源码、数据保持冻结，新结果单独保存。

- 复用 32³ 的六方法、双初值、三重复、原实现/串行/并行完整对比，明确其为上一轮数据。
- 64³：固定 α=0.5，初值 A/B，串行/并行，各三次完整优化。
- 128³：固定 α=0.5，初值 A，串行/并行各一次完整优化；最大 180 步。该规模不报告完整流程计时标准差。
- 32³、64³、128³：初值 A 的四个真实优化状态（索引 0、49、62、179），六种方法，GPU 并行模式，随机交错三次回放。每个状态以原通用算子和 1e-11 参考求解独立核验；正式解沿用原 1e-8/绝对残差判据。
- 每个状态另测原 CPU 与 GPU 的过滤、SIMP、链式灵敏度、45 次 OC 二分，三次重复。该分量测量不冒充完整 CPU 设计耗时。
- 两种模式在三个网格的独立进程测量显存；张量分配峰值和含上下文的设备采样占用分开报告。
- 所有网格保持单位单胞、体积分数0.30、eta=1e-4、p=3、move=0.10、相同初值生成规则与物理过滤尺度0.028125。不降低精度、不缩短大规模设计预算、不调整选择器。
- 保存真实大网格优化产生的密度、材料系数、能量和位移；插值试跑场只用于估计成本，不能充当128³优化结果。
- 几何按物理密度0.5等值面提取，固定阈值与相机。连续密度/系数截面不做阈值化或人为锐化。
- 全流程计时排除编译、预热、初值生成、快照下载和磁盘写入，包含每任务图捕获、逐载荷真实残差核验及小量状态传输。CUDA event阶段与数值墙钟闭合。
- 干扰导致该运行记录无效；监测外部GPU计算进程，不停止其他人的进程。

图形证据设计（Python，沿用现有工作流）：
1. 网格扩展与128³真实材料形态：三维表面+连续截面，建立计算对象和空间分辨率。
2. 目标值—累计时间及目标值—迭代步：区分相同物理结果与计算速度。
3. 同一状态上六方法时间与迭代数：识别规模增加后选参/预条件的相对表现。
4. 完整时间与分阶段费用：定位求解与外层工作占比。
5. 串行/并行的时间和显存：并列展示速度与资源取舍。
6. 128³阶段形态、系数、能量/位移分布：展示实际求解对象与力学响应。

定量图输出PNG、SVG、PDF和源CSV；技术重复使用样本标准差，单次结果不加误差棒。128³不作网格收敛证明，跨分辨率差异同时包含离散化与非凸设计轨迹变化。最终结论由实测数据决定。
